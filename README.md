# 4d-plugin-simple-postgres-client

Simple PostgreSQL client using libpq

* macOS library version:
  * `libpq-16.4` (homebrew)

* Windows library version:
  * `libpq-16.4` (vcpkg, `[core,lz4,openssl,zlib]`)
